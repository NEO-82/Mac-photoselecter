# 3영역 탐색·태그·휴지통

앱을 열면 왼쪽 폴더 트리, 가운데 현재 폴더의 ARW/JPG/JPEG 전체 목록, 오른쪽 선택 사진 미리보기가 나타납니다.
시작 폴더는 홈이며, 트리의 저장장치를 펼쳐 외장 드라이브에 접근합니다. 접근이 거부되면 폴더 열기에서 해당 폴더를 선택하세요.
폴더 트리와 파일 목록은 비동기로 읽습니다. 숨김 파일/심볼릭 링크는 제외하고 선택 폴더의 사진만 열거합니다.
썸네일 아래 파일명을 두 줄까지 표시하고, 전체 이름은 마우스를 올려 확인할 수 있습니다. 오른쪽 미리보기 아래에도 파일명이 표시됩니다.

## 큰 사진 창

더블클릭하면 제목 표시줄과 크기 조절이 있는 일반 창을 화면의 `visibleFrame` 크기로 엽니다.
Dock과 메뉴 막대를 덮지 않고 별도 전체 화면 Space로 전환하지 않습니다. Dock 자동 가리기는 macOS의 사용자 설정을 따릅니다.
←/→로 사진 이동, 왼쪽 버튼을 누르는 동안 물리 픽셀 1:1 확대, 놓으면 맞춤, Esc로 목록 복귀합니다.
누른 채 사진을 넘기거나 휴지통으로 옮긴 뒤 다음 사진이 표시되어도 버튼을 놓을 때까지 확대 상태를 유지합니다.

## 태그

선택 사진에서 `\` 키를 누르면 태그를 켜거나 끕니다. 한글 키보드의 같은 위치 `₩` 키도 지원합니다.
태그는 썸네일·오른쪽 미리보기·큰 사진 창의 오른쪽 위 빨간 네모로 표시합니다.
키를 길게 눌렀을 때 자동 반복으로 태그가 깜박이지 않도록 반복 이벤트는 무시합니다.

사진 파일/EXIF/RAW를 수정하지 않습니다. 다음 별도 파일에 버전 1 JSON을 저장합니다.

```text
~/Library/Application Support/dev.photoselect.app/tags.json
```

파일별 절대 경로를 기준으로 RAW와 동명 JPEG를 독립적으로 취급합니다. JSON 갱신은 직렬 큐에서 원자적 파일 교체로 수행하고,
저장에 성공한 상태만 화면에 반영합니다. 기존 JSON이 손상됐거나 지원하지 않는 버전이면 덮어쓰지 않고 오류를 알립니다.
외부 프로그램에서 사진 이름/위치를 바꾸면 태그는 자동으로 따라가지 않습니다. 태그 필터와 일괄 이름 변경은 포함하지 않습니다.

## 휴지통

선택 사진에서 Mac Delete 또는 Forward Delete(`fn`+Delete)를 누르면 현재 파일 한 장을 `FileManager.trashItem`으로 옮깁니다.
확인 창 없이 실행하며, 키 자동 반복과 진행 중 중복 요청은 무시합니다. 동명 RAW/JPEG 중 선택한 한 파일만 옮깁니다.
성공 후 다음 사진, 마지막이었다면 이전 사진을 선택합니다. 마지막 한 장을 옮기면 큰 사진 창을 닫고 빈 목록으로 돌아옵니다.
이동 중 다른 사진/폴더를 선택하더라도 요청 당시 파일만 이동하며 현재 선택을 보존합니다.
권한/장치 문제로 휴지통 이동이 실패하면 오류를 표시하고 영구 삭제로 대체하지 않습니다.
복원은 macOS 휴지통의 되돌려 놓기를 사용하세요. 원래 경로로 복원하면 보존된 태그도 다시 표시됩니다.

## 실제 Mac에서 확인

1. 3영역의 너비를 조절하고, 트리 하위 폴더/외장 드라이브 선택 시 목록과 오른쪽 미리보기가 일치하는지 확인합니다.
2. JPG/ARW를 선택해 `\`를 켜고 끈 뒤 앱 재시작 후 상태를 확인합니다. 동명 RAW/JPEG가 독립적으로 태그되는지 확인합니다.
3. 복구 가능한 테스트 사진으로 누른 채 확대 → Delete → 다음 사진 → 버튼 해제를 확인하고, 휴지통에서 원본을 복원합니다.
4. 첫/마지막/한 장만 남은 폴더, 이동 권한 거부, 외장 드라이브 해제, 로딩 중 방향키/태그/삭제를 확인합니다.
5. 큰 창이 Dock을 덮지 않는지 확인합니다. Dock 자동 가리기를 켰다면 화면 가장자리에서 정상적으로 나타나는지 확인합니다.
