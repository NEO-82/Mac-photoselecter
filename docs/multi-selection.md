# v0.7.0 — 다중 선택과 선택 파일 이름 변경

## 사용

- 일반 클릭은 한 장 선택, ⌘클릭은 개별 추가/해제, ⇧클릭은 기준 사진부터 현재 화면 순서의 범위 선택입니다. 기준 사진은 파일 식별자로 유지하므로 정렬 후에도 해당 파일의 새 위치를 기준으로 합니다.
- ⌘A는 현재 정렬·태그 필터로 표시된 **사진** 전체를 선택합니다. 폴더와 일반 문서는 제외합니다. 화면 밖의 사진도 포함합니다.
- 빈 공간에서 드래그하면 로즈 색 선택 사각형이 표시됩니다. 가장자리에서는 자동 스크롤합니다. ⌘드래그는 토글, ⇧드래그는 기존 선택에 추가합니다.
- Escape는 선택을 해제하고 현재 미리보기는 유지합니다. 선택 배경과 현재 표시 중인 사진의 테두리는 구분됩니다. 하단에는 선택 수를 표시합니다.
- 자동으로 표시되는 첫 미리보기는 명시적인 다중 선택과 별개입니다. 선택이 없는 상태에서 이름 변경 창을 열면 폴더 전체가 기본값입니다. 선택을 해제한 브라우저의 Delete는 아무 파일도 이동하지 않습니다.
- 정렬과 새로고침에서는 같은 파일의 선택을 유지합니다. 태그 필터로 제외된 사진은 선택에서 제외하며 다른 폴더로 이동하면 선택을 초기화합니다.

## 일괄 이름 변경

기존 상단 버튼을 사용합니다. 창 위에서 ‘선택한 파일만 변경’과 ‘현재 폴더 전체 변경’을 전환할 수 있습니다. 선택이 있으면 선택 범위가 기본값이며, 선택이 없으면 해당 범위는 비활성화됩니다. 폴더 전체 범위는 숨김 표시/태그 필터와 관계없이 현재 폴더의 지원 이미지 전체를 대상으로 합니다. 하위 폴더와 macOS `._` 파일은 제외합니다.

번호는 현재 적용된 정렬 기준과 방향을 따릅니다. 기존 접두어·구분자·시작 번호·자릿수·확장자 유지·전후 이름 비교 기능을 유지하며, 범위 전환 시 개수와 미리보기를 다시 계산합니다. 실행 버튼에는 실제 이름이 바뀌는 파일 수를 표시합니다. ARW/JPG는 같은 이름이어도 독립 파일입니다.

선택 대상 및 폴더의 다른 모든 이름과 충돌을 검사합니다. Unicode 정규화와 대소문자 접기를 보수적으로 적용하며 OS의 덮어쓰기 금지 이름 변경을 사용합니다. 원본 파일을 열어 쓰거나 복사하지 않습니다. 각 파일은 같은 폴더 안에서 UUID 임시 이름을 거쳐 새 이름으로 이동합니다. 오류 시 원래 이름 복구와 태그 재연결을 시도하며 미복구 위치/저널을 보고합니다.

선택은 장치·inode·생성 시각으로 관리하며 하드 링크는 경로로도 구분합니다. 기존 엔진의 중복 하드 링크 복구 제한을 유지합니다. 실행 전 파일 목록·식별자·크기·수정/변경 시각을 재검증하고, 각 파일을 임시 이름으로 변경하기 직전에도 상태를 확인합니다. 외부 프로그램에서 바뀐 파일은 실행을 중단하고 복구 경로로 들어갑니다.

## 휴지통과 뷰어

브라우저에서 여러 장 선택 후 Delete를 누르면 대상 수가 표시된 확인창이 열립니다. 취소는 파일과 선택을 유지합니다. 실행 후 각 파일의 결과를 확인하며 일부만 실패하면 완료/실패 목록을 표시하고 실패한 사진의 선택을 유지합니다. OS 휴지통을 지원하지 않는 저장장치에서 영구 삭제로 대체하지 않습니다.

한 장 선택 후 Delete에는 확인창을 추가하지 않습니다. 큰 사진 뷰어의 Delete는 브라우저의 다중 선택과 관계없이 **현재 사진 한 장**만 기존 경로로 즉시 처리합니다. 확대 누름·드래그 입력은 PhotoCanvas에 유지하고 썸네일 입력과 분리했습니다. ARW 내장 JPEG 추출·이미지 캐시·프리페치 코드는 변경하지 않았습니다.

## 검증

macOS CI에서 전체 XCTest, Release Sony RAW/탐색 회귀 4개, 3,005장 Release 선택 측정, arm64 Release 앱·서명·DMG·아이콘 검증을 수행합니다. 설치 파일과 실제 측정 결과는 해당 빌드가 성공한 뒤 아래에 기록합니다.

자동 검사는 네이티브 Command/Shift 클릭 이벤트, ⌘A/Escape, 정렬 후 기준/선택 유지, 드래그 좌표와 화면 밖 선택·자동 스크롤, 태그 필터와 범위 전환, 선택 ARW/JPG 이름 변경·비선택 데이터 보존·태그 연결, 충돌·실행 직전/도중 상태 변경·복구, 삭제 취소·부분 실패, 다중 선택 상태의 뷰어 확대 중 단일 삭제를 포함합니다.

실기기에서는 3,000장 이상의 실제 촬영 폴더에서 물리 마우스로 빈 공간 드래그·가장자리 정지 자동 스크롤·⇧/⌘클릭을 확인하고, 다중 선택한 채 뷰어에서 누름 확대·방향키·Delete·놓기를 확인하세요. 실제 SD/SSD의 접근·분리·휴지통 복원, Apple Silicon 실기기 장시간 성능은 CI 결과와 별도로 검증해야 합니다.
